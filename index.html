Download & install

Desktop release 0.1.5 · x64

Windows 10 & 11

x64 · .exe

Download for Windows
  1. Open Vellire_0.1.5_x64-setup.exe.
  2. Follow the setup prompts. Setup may download Microsoft Edge WebView2 if needed.
  3. Open Vellire from the Start menu.

System-wide typing is available on Linux through IBus. On Windows, styling works inside Vellire.

Debian-based Linux

Ubuntu, Zorin OS and compatible systems · x64

Download for Linux
  1. Open a terminal in the Downloads folder.
  2. Run the command below.
  3. Open Vellire and choose a style. If IBus fails to activate, select Retry activation.
sudo apt install ./vellire_0.1.5_amd64.deb

Good to know

Why do some styles look different after pasting?

The styles use Unicode characters. Their appearance depends on the font and app that display them. Some characters may appear plain or as missing glyphs.

Why does typing stay plain in some fields?

Live typing requires IBus on Linux and a compatible text field. Vellire keeps password, private and terminal fields plain. In the app, choose Use Normal to return to standard text.

Do I need an account?

You can preview text and use the local typing features without signing in. Google sign-in is optional.

How do I uninstall?

On Windows, remove Vellire under Settings → Apps. On Debian-based Linux, run sudo apt remove vellire.
